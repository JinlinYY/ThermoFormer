# Results

This directory is the public-facing result layer modeled after PSMI's canonical result packages.

- `main_text/summary/` contains the distributed VLE/LLE summary tables and figures.
- `supporting_information/` records the SI result boundary and links to task-level evidence.
- `manifests/` documents result provenance and checksums.

The full task-level records remain under `experiments/` so that code, configuration, and evidence can be reviewed together.
