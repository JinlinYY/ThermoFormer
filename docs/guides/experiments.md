# Experiment design

Experiments are organized by the scientific question posed in the manuscript: predictive performance, comparison, ablation, interpretation, and separation design. Runnable leaves contain a strict configuration, a reproducible command, and a scientific result record. Planned studies are marked `not_evaluated` and contain no numerical placeholders.

The executable task view is under [`../../experiments/`](../../experiments/). The paper-section view is under [`../../experiments/section_2_results/`](../../experiments/section_2_results/) and [`../../experiments/supporting_information/`](../../experiments/supporting_information/).

See the [experiment overview](../reference/experiment_overview.md) and [experiment code map](../reference/experiment_code_map.md) for the manuscript mapping.
