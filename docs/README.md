# Documentation hub

This documentation layout follows the task-oriented structure used by PSMI.

- [`getting_started/`](getting_started/) — installation, quick start, and research workflow.
- [`architecture/`](architecture/) — scientific model, interfaces, and repository contract.
- [`guides/`](guides/) — data, training, experiments, reproduction, and baseline workflows.
- [`reference/`](reference/) — registries, provenance, experiment mapping, and compatibility notes.
- [`results/`](results/) — paper and Supporting Information result navigation.
- [`development/`](development/) — contribution and code-quality conventions.
- [`legal/`](legal/) — third-party attribution and reuse notes.

The older files directly under `docs/` remain compatibility entry points for recorded manifests. New documentation should be added to one of the directories above.
