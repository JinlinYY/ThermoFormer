# Research guide

ThermoFormer is a research codebase for reproducible vapour–liquid and liquid–liquid equilibrium studies.

Start with the [reproducibility guide](reproduction.md), then use the following resources:

- [Repository architecture](../architecture/repository_layout.md)
- [Experiment catalog](../reference/experiment_overview.md)
- [Dataset registry](../../datasets/README.md)
- [Checkpoint registry](../../models/README.md)
- [Scientific scope and manuscript alignment](../results/article_scope.md)
- [Article and SI experiment index](../results/article_experiment_index.md)

List registered experiments with `python scripts/run_experiments.py list`.
