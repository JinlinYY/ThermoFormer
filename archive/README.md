# Archive

The archive preserves source material that is not imported by active model,
training, evaluation, or report-generation workflows. Archived files remain in
version control for provenance and are excluded from supported research entry
points.

See [`legacy_code/README.md`](legacy_code/README.md) for preserved programs.
`legacy_artifacts/` contains early-model figures and development-stage audit or
diagnostic reports that are not part of the manuscript evidence package.
