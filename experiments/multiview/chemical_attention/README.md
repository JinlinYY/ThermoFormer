# C1 interaction-module ablations

This retained five-seed comparison is restricted to `overall_binary_ternary`:

- C0: Uni-Mol v2 + vanilla Transformer;
- C1: RDKit + Uni-Mol + FG + vanilla Transformer (selected final model);
- C2: three views + chemical attention bias + context pair interaction;
- C3: three views + context pair interaction, without attention bias.

All four variants use data-supervised training only (`epochs_physics=0`). Data,
split, `G^E/RT -> ln(gamma)`, pure-property branch, VLE solver and metrics are
unchanged.

```powershell
conda run -n ggnn39 python scripts\run_chemical_attention_suite.py --device cuda
```

The consolidated four-output MAE/RMSE/R² comparison is generated by
`scripts/build_c1_ablation_report.py`.
