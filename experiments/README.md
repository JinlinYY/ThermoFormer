# Experiments

This directory has two complementary views, following the PSMI release convention:

- task-organized executable studies under [`vle/`](vle/), [`lle/`](lle/), and [`data_quality/`](data_quality/);
- paper-organized navigation under [`section_2_results/`](section_2_results/) and [`supporting_information/`](supporting_information/).

The paper view links to canonical task paths and does not duplicate model code. Run commands from the repository root so configuration and dataset paths resolve consistently.
