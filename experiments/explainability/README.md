# Explainability experiments

This category contains post-hoc molecular-view attribution, thermodynamic
sensitivity and learned-interaction analyses.

The active experiment is `c1_final/`. It explains the five validation-selected
checkpoints of C1 (RDKit + Uni-Mol v2 + functional groups + vanilla Transformer,
with fugacity-only fine-tuning when selected) on `overall_binary_ternary`.

The older `analysis/interpretability/` campaign belongs to the superseded model
and is retained only as historical evidence. It must not be cited as the final
model's explanation.
