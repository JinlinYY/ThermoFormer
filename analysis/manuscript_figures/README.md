# Manuscript figures

This directory contains the exact raster object used for manuscript Figure 2.
The image was losslessly extracted from page 10 of the frozen manuscript PDF;
its dimensions are 3157 × 2878 pixels and its SHA-256 digest is recorded in
`Figure_2_interpretability.source.json`.

The current source tree does not contain the original six-panel assembly program
or all intermediate tables used to produce this figure. Earlier interpretability
programs and their scientifically different four- and six-panel outputs are
therefore retained under `archive/` and are not identified as manuscript Figure 2.
